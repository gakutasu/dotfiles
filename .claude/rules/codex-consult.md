# Codex への相談
次の場面では、codex-consult skill に従って Codex に相談する。意見が割れたら議論し、合意できなければユーザーの判断を仰ぐ。議論の内容は必ずユーザーに伝える。

- 調査結果の検証
- 方針・設計の判断
- 非自明なコード編集の後
- ユーザーが Codex への相談を求めたとき
- pr skill / issue skill の使用時: プレビューをユーザーに見せる前に、下書きを Codex に確認させる。PR は下書きと実際の差分の整合性や書き漏れ、issue はリポジトリと照らした記述の正確さと分かりやすさを見てもらう。Codex の意見（議論した場合はその内容も）をプレビューと一緒に伝える
- PR レビュー・コードレビュー: 使う skill にかかわらず、Codex にも独立してレビューさせ、両者の指摘を突き合わせる
