# Codex への相談
Codex への相談は codex-consult skill に従う。意見が割れたら議論し、合意できなければユーザーの判断を仰ぐ。議論の内容は必ずユーザーに伝える。

必ず相談する場面:
- ユーザーが Codex への相談を求めたとき
- pr skill / issue skill の使用時: プレビューをユーザーに見せる前に、下書きを Codex に確認させる。PR は下書きと実際の差分の整合性や書き漏れを、issue はリポジトリと照らした記述の正確さと分かりやすさを見てもらう。issue では、セッション中に観測したエラーやログも依頼文に含める。Codex の意見（議論した場合はその内容も）をプレビューと一緒に伝える
- PR レビュー・コードレビュー: 使う skill にかかわらず、Codex にも独立してレビューさせ、両者の指摘を突き合わせる

Claude が判断して相談する場面（不確実さが高い、影響が大きい、独立した検証で誤りを減らせる、のいずれかに当たる場合）:
- 調査結果の検証
- 方針・設計の判断
- 非自明なコード編集の後

重複を避ける:
- 同じ論点は、その作業を担当した側だけが相談する。サブエージェントに委譲した作業の論点はサブエージェントが相談し、親はその報告を引き継いでユーザーに伝える
- 委譲するときは、相談の要否と論点を指示に含める
