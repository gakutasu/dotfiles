# タスク実行
- 時間がかかる作業（複数ファイルの調査・編集・監視など）や独立したサブタスクが2つ以上ある作業は、分解してバックグラウンドのサブエージェントに委譲する。並列化は superpowers:dispatching-parallel-agents に従う
- 委譲したらターンを終え、メインはユーザーの次の指示を受けられる状態を保つ。結果は完了通知を受けてから伝える
- トークン消費は気にしなくてよい。サブエージェントを使うか迷ったら使う側に倒す。ただし数回のツール呼び出しで済む作業や、同一ファイルへの編集は並列化しない
- 長時間のコマンドや監視は、バックグラウンド実行や Monitor を使い、メインで待たない
- 大規模なタスク（多数ファイルの監査・レビューなど）で Workflow が有効そうなら、規模とコストの目安を添えて使用を提案する
