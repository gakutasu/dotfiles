# タスクボード

ユーザーのタスクは Artifact「毎朝タスクボード」で管理する。ユーザーは仕事始めにこれを見て、その日にやることを決める。

- URL: https://claude.ai/artifact/FCjrSV3hjR6bHcWjCwkCQ5
- データは Artifact のデータベースにあり、`ArtifactData`（`ToolSearch` で `select:ArtifactData`）で読み書きする。ページの再発行は不要
- フィールドの形は既存のタスクに合わせる。同期の規則は routine のプロンプトにある

## 更新するとき

セッション中の作業でタスクの状態が変わったら、区切りのよいところでボードを更新する。更新したことは一言伝える。

- タスクが終わった（PR を作成した、レビューを投稿した、実機確認が済んだ、文書を提出した）: `status` を `done`、`done_at` を現在時刻、`today` を `false` にする
- 途中まで進んだ、相手待ちになった: `status`、`next`、`waiting_on` を書き直す
- 新しい作業が生まれた（あとでやると決めたこと、頼まれたこと、見つけた不具合）: タスクを追加する
- ユーザーが優先度や期限を口にした: その通りに直す

## 守ること

- 書く前に対象の文書を読み、`if_version` を付ける。ユーザーの編集を上書きしない
- `updated_at` に現在時刻（UTC の ISO 8601）、`updated_by` に `claude` を入れる
- `updated_by` が `me` のタスクの `priority`、`today`、`title` は、ユーザーに言われたとき以外は変えない
- `status` が `dropped` のタスクはユーザーが削除したもの。復活させない
- 数回のツール呼び出しで済むので、サブエージェントには委譲しない

## GitHub との同期

ローカルの常駐サービスは使わない（ユーザーの方針）。定期実行は Claude のクラウド routine「タスクボード同期」が行い、平日 8:00〜22:00 の毎時（実際の起動は数分遅れる）、GitHub の変化（マージ、新しいレビュー依頼、assign）と、Slack の自分宛てメンション・DM のうち未返信の依頼や質問をボードに反映する。その日の最初の実行では「今日やる」を 3 件まで補う。routine の一覧は https://claude.ai/code/routines にある。

routine は GitHub を検索でしか見られず、検索に出ないリポジトリがある（メモリ `task-board-artifact` を参照）。そのリポジトリのタスクは自動では変わらないので、状態が変わったらセッション中に手で更新する。

routine は日曜の日中と土曜の朝にも起動するが、プロンプトの指示で土日は何もせずに終わる。土日に同期を頼まれたら、routine では反映されないと伝える。

同期の規則を変えるときは、routine のプロンプトを直す（`RemoteTrigger` の `get` で読み、`update` で書く）。手元に写しは置かない。

「今日のタスク」「ボードを同期して」と言われたら、routine を `RemoteTrigger` の `run` で 1 回動かし、終わったらボードを読んで今日やる分を伝える。
